## Repository layout

```
projects/
  <project-name>/
    cad/        native CAD files (parts, assemblies)
    exports/    STEP / STL / DXF for anyone without the software
    drawings/   engineering drawings (PDF)
    renders/    images used in the README
    docs/       analysis, hand calcs, reports
    README.md   what it is, design goals, results
```

## Viewing the files

See [SOLIDWORKS-WORKFLOW.md](SOLIDWORKS-WORKFLOW.md) for how projects are added.

Large CAD files are stored with [Git LFS](https://git-lfs.com). Clone with Git LFS installed, or download the STEP and eDrawings files in `exports/`. They open in any CAD tool or the free [eDrawings Viewer](https://www.edrawingsviewer.com).
