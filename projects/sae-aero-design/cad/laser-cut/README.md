# Laser-cut balsa sheets

DXF cutting layouts for 1/8 in balsa. Each sheet fits a 48 × 12 in (1219 × 305 mm) cutting bed.

![All cutting sheets](../../renders/laser-cut-sheets.png)

| File | Contents |
|---|---|
| `Sidelarge.DXF` | Fuselage side panels (triangulated truss) and a square bulkhead with a round cutout |
| `Sidelarge_v2.DXF` | Revised fuselage side panels |
| `Top_and_bottom.DXF` | Fuselage top and bottom panels |
| `Top_Bottom_Front_Support.DXF` | Fuselage top and bottom truss panels, front bulkheads, ribs and triangular gussets |
| `Top_and_Bottom_and_4_airfoils.DXF` | Fuselage top and bottom panels with lightening cutouts, plus 4 wing ribs |
| `Side_and_wings.DXF` | Fuselage sides and wing ribs (`Side_and_wings.SLDDRW` is its SolidWorks drawing) |
| `Wing.DXF` | Wing ribs, spars and triangular rib gussets |
| `Wing_Spars.DXF` | Wing spars with lightening cutouts, plus tail ribs |
| `Ribs_with_holes.DXF` | Lightened wing ribs, spars and gussets |
| `New_Aileron_assembly.DXF` | Aileron ribs and spars |
| `Side_Tail_and_right_back.DXF` | Tail boom sides, ribs and spar strips |
| `Tail_side_and_bottom_Horizontal_Stabilizer.DXF` | Tail boom side and bottom, and horizontal stabilizer ribs |
| `TailBottom_back_and_Brace.DXF` | Tapered tail bottom panel and rear bulkhead |
| `Back_drawing.DXF` | Rear fuselage and tail truss panels, tail ribs and bulkheads |
| `Fix_1.DXF` | Replacement fuselage panels, ribs and a bulkhead |
| `Rebuild2.DXF` | Second set of rebuild parts: fuselage sides, ribs and bulkhead |

Duplicate exports were removed: only one copy of each identical layout is kept.
